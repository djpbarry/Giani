********************************
Running GIANI Headlessly
********************************

.. highlight:: shell

Overview
========

If you wish to run GIANI in environments with no graphical capabilities (e.g. HPC clusters), you can use "headless" mode, which runs GIANI as a command line tool. In order to run GIANI in headless mode, you will need a ``properties.xml`` file. If you do not have one, it can be generated by using the graphical user interface in FIJI to specify the parameters for your analysis - every analysis saves its parameters to ``properties.xml`` in its output folder.

When running GIANI in headless mode, you must specify at least:

* The location of a ``properties.xml`` file
* The image file to be processed.

GIANI is run through FIJI's own launcher, so that all of FIJI's libraries are available. For example, on Windows, the following command will run GIANI on ``test_image.ome.tiff`` using ``properties.xml``::

   <Path to FIJI>\fiji-windows-x64.exe --headless --main-class=net.calm.giani.exec.GIANI -- -f test_image.ome.tiff -p properties.xml

On Linux, use the corresponding launcher in the FIJI directory::

   <Path to FIJI>/fiji-linux-x64 --headless --main-class=net.calm.giani.exec.GIANI -- -f test_image.ome.tiff -p properties.xml

Replace ``<Path to FIJI>`` with the full path to your FIJI installation. Note the ``--`` on its own: options before it are for the FIJI launcher, and options after it are passed to GIANI.

.. note:: On Windows, the FIJI launcher does not print GIANI's progress messages to the terminal. Check the output folder to confirm the analysis has completed.

Parameters
==========

The full list of parameters that can be passed to GIANI (after the ``--``) is as follows:

* ``-f``: The full path to the image file you wish to analyse.
* ``-p``: The full path to the ``properties.xml`` file.
* ``-s``: If the input image file contains multiple image series, the series you wish to analyse (numbered from 0). If not specified, the first series (``0``) is analysed.
* ``-o``: The directory where you wish outputs to be saved. If not specified, GIANI creates an output folder next to the input file. The output folder is named ``GIANI-X.Y.Z_<image file name>_S<series>_Output``.

Deprecated parameters - will be removed in a future release:

* ``-l``: The full path to a CSV file containing a list of image files you want GIANI to analyse (see below).
* ``-n``: If a list of files was provided above, this parameter tells GIANI which file in the list to analyse (see below).

Path to GIANI job list (Deprecated - will be removed in a future release)
-------------------------------------------------------------------------

The full path to a text file containing a list of all the images you wish to analyse with GIANI. The format of this file is very simple and should contain the following:

``0, <Path to Image 1>, 0``

``1, <Path to Image 2>, 0``

``2, <Path to Image 3>, 0``

and so on. The first column specifies the job number, which can be specified by the ``-n`` parameter when running GIANI. The second column lists the images to be analysed. The final column specifies the series within the specified file that is to be analysed.

Running GIANI from an ImageJ macro
==================================

GIANI can also be driven from the `ImageJ Macro Language <https://imagej.net/ij/developer/macro/macros.html>`__ via a macro extension. The following functions are available:

* ``Ext.GIANI.loadPropertiesFile(path)`` - load parameters from a ``properties.xml`` file.
* ``Ext.GIANI.setProperty(name, value)`` - set a single parameter. ``name`` is the parameter's name as it appears in ``properties.xml`` (e.g. ``"Input Directory"``); ``value`` is always given as a string.
* ``Ext.GIANI.getPropertyList()`` - returns a comma-separated list of all parameter names.
* ``Ext.GIANI.run()`` - run the analysis with the current parameters.

For example, to apply a saved set of parameters to a different directory:

.. code-block:: javascript

   Ext.GIANI.loadPropertiesFile("/path/to/properties.xml");
   Ext.GIANI.setProperty("Input Directory", "/path/to/images");
   Ext.GIANI.setProperty("Output Directory", "/path/to/output");
   Ext.GIANI.run();
